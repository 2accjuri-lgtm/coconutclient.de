A lightweight launcher for Minecraft: Java Edition.

Ein schlanker Launcher für Minecraft: Java Edition.

Coconut Launcher is a personal project: it signs in with a Microsoft account, starts the official game files and keeps resource usage as low as possible. Everything runs on your own computer.

Coconut Launcher ist ein privates Projekt: Er meldet sich mit einem Microsoft-Konto an, startet die offiziellen Spieldateien und hält den Ressourcenverbrauch so niedrig wie möglich. Alles läuft auf dem eigenen Rechner.

~70 MB RAM for the launcher ~70 MB RAM für den Launcher < 1 % CPU per idle instance without rendering < 1 % CPU je Instanz ohne Grafik im Leerlauf No tracking, no analytics Kein Tracking, keine Analyse

What it does

Was er kann

Everything a launcher needs, plus a few things for running the game with as little load as possible.

Alles, was ein Launcher braucht, und dazu ein paar Dinge, damit das Spiel möglichst wenig Last erzeugt.

Microsoft sign-in

Microsoft-Anmeldung

Official Microsoft login with a one-time code. The launcher never sees your password.

Offizieller Microsoft-Login per Einmal-Code. Der Launcher sieht dein Passwort nie.

Official game files

Offizielle Spieldateien

Game, libraries, assets and the matching Java runtime are downloaded directly from Mojang and checked by checksum.

Spiel, Bibliotheken, Assets und das passende Java kommen direkt von Mojang und werden per Prüfsumme kontrolliert.

Low resource usage

Wenig Ressourcen

Optional Fabric with performance mods from Modrinth, tuned memory settings and a mode that skips rendering entirely.

Optional Fabric mit Performance-Mods von Modrinth, abgestimmte Speichereinstellungen und ein Modus ganz ohne Grafik.

Local dashboard

Lokales Dashboard

A small web dashboard on your own computer shows FPS, CPU, memory and status of your instances.

Ein kleines Web-Dashboard auf dem eigenen Rechner zeigt FPS, CPU, Speicher und Status der Instanzen.

How the sign-in works

So funktioniert die Anmeldung

The launcher uses Microsoft's device code flow with the scopes XboxLive.signin and offline_access. These are the only steps:

Der Launcher nutzt den Gerätecode-Ablauf von Microsoft mit den Berechtigungen XboxLive.signin und offline_access. Das sind alle Schritte:

  1. You get a short codeDu bekommst einen kurzen Code and enter it yourself on microsoft.com/link. Your password is typed only into Microsoft's own page. und gibst ihn selbst auf microsoft.com/link ein. Dein Passwort tippst du nur auf Microsofts eigener Seite.
  2. Microsoft issues a tokenMicrosoft stellt ein Token aus for Xbox Live sign-in only (login.microsoftonline.com). nur für die Xbox-Live-Anmeldung (login.microsoftonline.com).
  3. Xbox Live and XSTSXbox Live und XSTS turn it into an Xbox identity for Minecraft services (user.auth.xboxlive.com, xsts.auth.xboxlive.com). machen daraus eine Xbox-Identität für die Minecraft-Dienste (user.auth.xboxlive.com, xsts.auth.xboxlive.com).
  4. Minecraft access token and profileMinecraft-Token und Profil The launcher gets a game token and reads your player name and UUID (api.minecraftservices.com). Der Launcher bekommt ein Spiel-Token und liest Spielername und UUID (api.minecraftservices.com).
  5. The game startsDas Spiel startet The token is handed to the official game process on your computer, exactly like the official launcher does. Das Token wird an den offiziellen Spielprozess auf deinem Rechner übergeben, genau wie beim offiziellen Launcher.
No other Microsoft or Minecraft APIs are used. The launcher cannot read your e-mail, contacts, purchases or anything else from your account.
Es werden keine weiteren Microsoft- oder Minecraft-Schnittstellen genutzt. Der Launcher kann weder E-Mails, Kontakte, Käufe noch sonst etwas aus deinem Konto lesen.

Privacy

Datenschutz

Short version: your data stays on your computer.

Kurz gesagt: Deine Daten bleiben auf deinem Rechner.

  • Sign-in tokens are stored only in a local file on your computer. Removing the account in the launcher deletes them.
  • There is no Coconut server. Nothing is sent to the developer or to any third party.
  • No telemetry, no analytics, no ads, no crash reporting to anyone.
  • The dashboard is only reachable from your own computer unless you deliberately enable network access, which then requires an access key.
  • This website loads no external fonts, scripts or trackers and sets no cookies.
  • Anmelde-Tokens liegen nur in einer lokalen Datei auf deinem Rechner. Entfernst du das Konto im Launcher, sind sie gelöscht.
  • Es gibt keinen Coconut-Server. Nichts wird an den Entwickler oder an Dritte gesendet.
  • Keine Telemetrie, keine Analyse, keine Werbung, keine Absturzberichte an irgendwen.
  • Das Dashboard ist nur vom eigenen Rechner erreichbar, außer du schaltest den Netzwerkzugriff bewusst ein. Dann ist ein Zugangsschlüssel nötig.
  • Diese Webseite lädt keine externen Schriften, Skripte oder Tracker und setzt keine Cookies.
